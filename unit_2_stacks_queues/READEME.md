# Unit 2: Stacks and Queues
This assignment demonstrates how stacks (LIFO) and queues (FIFO) work in Python.
It includes stack and queue operations, empty structure testing, and real-world customer support example.

What I Completed
Implemented stack operations such as push, pop, and peek.
Implemented queue operations such as enqueue, dequeue, and front.
Demonstrated LIFO and FIFO behavior.
Tested empty stacks and queues.
Tested removing a single item.
Created a real-world customer support example using a queue.
What I Learned
This assignment helped me better understand how stacks and queues organize and process data. I learned that stacks remove the most recently added item first, while queues process items in the order they were added.
I also learned the importance of testing my code and correcting errors when the program does not run as expected.
